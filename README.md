# JavaScript Expense Tracker Web App

Project 12 of my 30 JavaScript Projects Challenge.

An interactive Expense Tracker Web App built using HTML, CSS, and Vanilla JavaScript that allows users to manage income and expenses, track their balance, and maintain transaction history using Local Storage.

---

## Features

- Add income and expense transactions
- Edit and delete existing transactions
- Automatically calculate the current balance
- Track total income and total expenses
- Categorize transactions for better organization
- Store transaction history using Local Storage
- Persistent data after page refresh
- Responsive and user-friendly interface

---

## Architecture Approach

The application uses a state-driven approach with JavaScript objects, arrays, and Local Storage to manage financial transactions.

- Transactions are stored as structured data in an array
- Users can create, view, edit, and delete transactions
- Array methods calculate total income, expenses, and current balance
- Local Storage preserves transaction data across page reloads
- The interface updates dynamically whenever transaction data changes
- Categories help organize transactions for easier tracking

---

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage API

---

- Working with DOM manipulation and event handling

- Managing application state using objects and arrays
